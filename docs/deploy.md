# Deploy (free tier): Neon + Render + Vercel

PAU OS is two deployables: the **web SPA** (`apps/web`, static) and the **API**
(`services/api`, Node + Postgres). Free-tier hosts:

| Piece | Host | URL |
|---|---|---|
| Database | Neon (Postgres) | `ep-…us-east-2.aws.neon.tech` |
| API | Render (`render.yaml`) | https://pau-os.onrender.com |
| Web | Vercel (`apps/web/vercel.json`) | https://pau-os.vercel.app |

> Render's free web service **sleeps after ~15 min idle** (first request cold-starts ~30s). Fine for a pilot.

## 0. Prerequisite
Commit and push to GitHub (`origin` = `github.com/fernandohonig/pau-os`). Render
and Vercel deploy from the repo.

## 1. Database (Neon)
Create a project and copy the pooled connection string (`…?sslmode=require`).
Apply schema + seed once (run locally with the Neon URL, or let Render's build
run migrations — see step 2):
```bash
DATABASE_URL="postgresql://…neon.tech/neondb?sslmode=require" pnpm db:migrate
DATABASE_URL="postgresql://…neon.tech/neondb?sslmode=require" pnpm db:seed
```
Seeded questions import as `pending_review`. Approve them (Admin → Review, or
bulk-approve) so diagnostics have content:
```sql
UPDATE "Question" SET "reviewStatus"='approved' WHERE "reviewStatus"='pending_review';
```

## 2. API (Render)
New → **Blueprint** → select this repo (`render.yaml` is picked up). Set the
dashboard secrets:
- `DATABASE_URL` — the Neon string
- `ADMIN_EMAILS` — e.g. `fernando@honig.com.ar`
- `GOOGLE_CLIENT_ID` — the OAuth **Web** client id
- `JWT_SECRET` — auto-generated by Render
- `CORS_ORIGINS` — preset to `https://pau-os.vercel.app`

The build runs `pnpm db:generate` + `pnpm db:migrate` automatically. Verify:
`https://pau-os.onrender.com/health` → `{"status":"ok"}`.

## 3. Web (Vercel)
New Project → import the repo → **Root Directory = `apps/web`** (Vite is
auto-detected; `vercel.json` supplies the build + SPA rewrite). Set env vars:
- `VITE_API_BASE_URL` = `https://pau-os.onrender.com`
- `VITE_GOOGLE_CLIENT_ID` = the OAuth Web client id

## 4. Google OAuth
GCP → Credentials → your **Web** OAuth client → **Authorized JavaScript
origins** → add `https://pau-os.vercel.app`.

## Dependency order
Neon → deploy API (needs `DATABASE_URL`) → deploy Web (needs the API URL) →
confirm `CORS_ORIGINS` = the Web URL on Render + Web URL in Google origins.

## Notes
- The API binds `0.0.0.0` and honors Render's `PORT` (`services/api/src/server.ts`).
- `NODE_ENV=production` on Render disables dev login — only Google + anonymous
  work in production, by design.
- **Rotate the Neon password** if the connection string has been shared anywhere.
